# TianDongXiao

写给可爱的晓同学的时光记忆小站 · [her.loser.dev](https://her.loser.dev)

## 页面结构

| 页面 | 说明 | 交互特色 |
|------|------|----------|
| `index.html` | 首页 · 视觉扉页 | 人物照片封面与章节导航 |
| `css/tdx.html` | 生日快乐 · 照片与视频 | 动态走过天数里程碑、鼠标/触屏悬停变身相片、独家小影院放映与全屏灯箱 |
| `css/wysn.html` | 网瘾少女田桑 · 战绩高光 | 还原真实名梗嘴炮（“时而大杀四方，时而唯唯诺诺，究其源，还是你菜”）、王者战绩高清展厅与富婆压轴喊话 |
| `css/nuli.html` | 雪日努力晓晓 · 冬日来信 | 静谧雪夜背景与毛玻璃手写信（“冲出南召的束缚，晓晓最棒”）、飘落雪花氛围粒子 |
| `css/surprise.html` | Surprise · 3D 时光魔方 | 3D 旋转相册魔方（支持手势拖拽旋转、悬停展开与合拢、六面相片原图灯箱） |

## 设计特点

- **纯正苹方（PingFang SC）**：基于 iOS / macOS 系统级字体规范，字重层次分明，文字清透凌厉。
- **温暖浅色页面**：以人物照片、生日祝福和回忆为主要内容。
- **全站高清画廊灯箱**：轻触任意照片或对局战报即可全屏查看原图细节。
- **极速纯静态**：零多余依赖，即开即看。

## 本地预览

npx serve .
