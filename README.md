# TianDongXiao

写给晓同学的小站 · [her.loser.dev](https://her.loser.dev)

## 页面

| 页面 | 说明 |
|------|------|
| `index.html` | 首页入口，卡片导航 |
| `css/tdx.html` | 生日快乐 · 照片与视频 |
| `css/wysn.html` | 网瘾少女田桑 · 游戏截图 |
| `css/nuli.html` | 雪日努力晓晓 · 加油寄语 |
| `css/surprise.html` | 大图轮播 + 拍立得选图 |

## 本地预览

纯静态站点，无需构建：

```bash
npx serve .
```

浏览器打开提示的本地地址即可。

## 设计说明

- 统一样式：`css/style.css`（浅色雏菊顶栏风格）
- 响应式布局
- 生日页按 2026-11-21 展示天数与年龄
- Surprise：自动轮播 + 拍立得缩略图
